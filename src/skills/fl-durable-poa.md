## Statutory Basis
Florida Statutes Chapter 709 (Florida Power of Attorney Act)
Substantially revised effective October 1, 2011.

## Key Statutory Rules
- Must be signed by principal in presence of two witnesses AND notary (§709.2105)
- All parties (principal, witnesses, notary) should be present simultaneously
- Springing POAs are NOT permitted in Florida (§709.2108) — must be immediately effective
- Agent must sign an acknowledgment/acceptance
- Healthcare decisions are NOT included — requires separate Designation of Health Care Surrogate
- Mental health treatment decisions require separate document

## Powers — Must Be Explicitly Granted
The following require SPECIFIC authority (cannot be implied):
- Create, amend, revoke or terminate a trust
- Make a gift
- Create or change survivorship rights
- Delegate authority to another agent
- Waive principal's right to be a beneficiary of a joint and survivor annuity
- Exercise fiduciary powers

## Agent Limitations (§709.2201)
- Agent cannot make gifts to themselves unless explicitly authorized
- Agent cannot change principal's will or estate plan unless explicitly authorized
- Agent owes fiduciary duty — must act in principal's best interest

## Successor Agent Rules
- Successor agent has authority only when primary agent is unable or unwilling to serve
- Should specify how successor authority is triggered (written statement of primary agent, 
  physician certificate, etc.)

## Co-Agent Rules
- If co-agents named, specify whether they must act jointly or may act independently
- Joint action is default — specify if independent action desired

## Execution Requirements — CRITICAL
- Principal signature
- TWO witnesses:
  * Cannot be the agent or agent's relatives
  * Each needs: signature + PRINTED NAME + ADDRESS
- Notary acknowledgment
- Agent acceptance signature (separate block)

## Common Issues — Flag with [REVIEW REQUIRED]
- [ ] Is principal competent at time of signing?
- [ ] Agent is also a witness? (prohibited)
- [ ] Are gift-giving powers needed? (must be explicit)
- [ ] Are trust powers needed? (must be explicit)
- [ ] Is successor agent named?
- [ ] If co-agents: joint or independent action?
- [ ] Is there a separate healthcare surrogate being done simultaneously?

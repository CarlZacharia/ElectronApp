# Will Review and Analysis
## Zacharia Frey PLLC — Analysis Skill

---

## Purpose
Analyze an existing will for legal sufficiency, execution defects,
outdated provisions, and planning gaps. Works for both FL and PA wills.

## Analysis Framework

### 1. Jurisdiction and Execution
- Identify governing jurisdiction from execution state and recitals
- Check execution formalities for that jurisdiction:
  FL: testator + 2 witnesses (printed names + addresses) + self-proving affidavit
  PA: testator + 2 witnesses (no address required) + optional self-proving affidavit
- Note any defects in execution that could invalidate the will

### 2. Personal Representative / Executor
- Is named PR/executor eligible?
  FL: must be FL resident or related by blood/marriage/adoption
  PA: no residency requirement
- Is there a successor named?
- Is bond waived?

### 3. Beneficiary Review
- Are all beneficiaries clearly identified?
- Are any beneficiaries deceased (lapse issues)?
- Are there minor beneficiaries without protective provisions?
- Are there disabled beneficiaries without special needs trust provisions?
- Has beneficiary changed status since will was drafted (divorce, death, disability)?

### 4. Asset Distribution
- Are specific bequests clearly described?
- Is residue clearly defined?
- Is there a pour-over to a trust? Does the trust still exist?
- Are digital assets addressed?
- Is tangible personal property addressed?

### 5. Outdated Provisions
- When was the will drafted? Is it more than 5 years old?
- Have there been major life changes since drafting:
  * Marriage / divorce / remarriage
  * Birth / adoption / death of children
  * Significant change in assets
  * Move to different state
  * Death of named beneficiary or PR

### 6. Missing Standard Provisions
Check for absence of:
- No-contest clause (in terrorem)
- Powers of personal representative
- Tax apportionment clause
- Simultaneous death / survivorship clause
- Digital assets clause
- Self-proving affidavit
- Specific disinheritance language (if applicable)

### 7. Medicaid / Asset Protection Issues
- Is there language that could interfere with Medicaid planning?
- Are there outright bequests to disabled beneficiaries on government benefits?
- Should assets pass to a special needs trust instead?

## Output Format
Provide analysis in this order:
1. EXECUTIVE SUMMARY — 2-3 sentences on overall status
2. JURISDICTION AND EXECUTION — findings and any defects
3. KEY PROVISIONS SUMMARY — what the will actually does
4. ISSUES IDENTIFIED — numbered list with severity (Critical/Major/Minor)
5. RECOMMENDATIONS — what should be done
6. QUESTIONS FOR CLIENT — what needs to be clarified

## Drafting Instructions for Claude
1. Read the attached will document completely before analyzing
2. Never invent provisions that are not in the document
3. State clearly when something is missing vs. when it is present
4. Use the analysis framework above in order
5. Flag all critical issues prominently
6. Note jurisdiction-specific rules that apply
